קישור צפייה חי למשפחה
נפתח במצב קריאה בלבד ומציג את מה שיש בשרת באותו רגע. כדי שהקישור יעבוד גם אצל מי שאינו בפרויקט, יש להעלות את קובץ היומן לאחסון סטטי (Vercel, Netlify, GitHub Pages) ולהחליף את תחילת הכתובת.
הקמה חד‑פעמית ב‑Supabase
  1. פותחים פרויקט חדש ב‑supabase.com (חינמי).
  2. ב‑SQL Editor מריצים את הקובץ supabase-schema.sql שנמצא בפרויקט — הוא יוצר את הטבלאות, ההרשאות ודלי המדיה.
  3. ב‑Settings → API מעתיקים את ה‑Project URL ואת ה‑anon key לשדות שלמעלה.
  4. לוחצים "העלאת כל היומן לשרת" פעם אחת, ומאותו רגע שני המכשירים מסונכרנים.
