# יומן המסע בנורווגיה

אפליקציית יומן מסע בעברית (RTL), מותאמת לנייד ולמחשב.

## קבצים

| קובץ | תפקיד |
| --- | --- |
| `Norway Travel Journal.dc.html` | האפליקציה — לוח המסע עם מפה, יומן יומי, ייבוא תכנית, סנכרון, שיתוף וספר המסע |
| `יומן המסע - קובץ לשיתוף.html` | קובץ עצמאי לצפייה, נפתח בכל דפדפן ללא התקנה |
| `supabase-schema.sql` | סכימת מסד הנתונים, ההרשאות, ה‑realtime ודלי המדיה |

## הקמת סנכרון חי

1. פרויקט חדש ב‑[supabase.com](https://supabase.com).
2. ב‑SQL Editor להריץ את `supabase-schema.sql`.
3. ב‑Settings → API להעתיק את ה‑Project URL וה‑anon key.
4. באפליקציה, בטאב **סנכרון**, להזין אותם וללחוץ "העלאת כל היומן לשרת".

מאותו רגע כל שמירה נשלחת לשרת, כל מכשיר שולף עדכונים כל 20 שניות, ונוצר קישור צפייה חי למשפחה (קריאה בלבד).

## פרסום כאתר

Settings → Pages → Branch: `main` → Save. הקישור שיתקבל יעבוד לכל אחד, ללא הרשאות.
